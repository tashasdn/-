# Проекты tashasdn

## PUSHKINS COFFEE

Исходники приложения кофейни находятся в [pushkins-coffee](./pushkins-coffee/). Это демонстрационная витрина с меню и корзиной. Для реальных заказов и платежей нужно подключить Telegram-бота, сервер и платёжного провайдера; инструкция — в README проекта.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save. Стартовая страница откроет приложение кофейни.

Другие репозитории пока не скопированы: на момент подготовки подключение GitHub показывало только этот пустой репозиторий. Для каждого дополнительного проекта будет использована отдельная папка; исходные репозитории не удаляются.
